# Extraction Guidelines

## What to Extract
Analyze BOTH the manuscript text AND all provided figures. For each cell type-marker gene pair:
- Infer the species/organism (use Latin names with underscores: homo_sapiens, mus_musculus, etc.)
- Extract EXACT text/labels as they appear in the source
- Match cell types to known types when possible
- Identify whether this came from text or figure (image)
- Provide evidence showing the relationship

## Cell Type Matching (IMPORTANT)
- For group_name: Match group_label to the MOST APPROPRIATE known cell type from the list above
- Use biological knowledge to match variants (e.g., "naive CD4+ T cells" matches "NAIVE CD4+ T CELL")
- Be flexible with matching: "T cell" vs "T-cell" vs "T_cell", "CD4+" vs "CD4+", etc.
- If no good match exists, normalize the group_label to UPPERCASE

## Source Types
- **TEXT**: Information from manuscript text → source_rationale is a verbatim excerpt (50-150 chars)
- **IMAGE**: Information from a figure → source_rationale describes what the figure shows (50-150 chars)

## Source Rationale Requirements
- For TEXT: Brief verbatim excerpt showing the relationship
- For IMAGE: Concise description (e.g., "Violin plot shows Cd19 expression in B cell cluster")
  - Mention figure element type (heatmap, UMAP, violin plot, etc.)
- MUST include BOTH the cell type AND gene name in ALL rationales

## Normalization Rules
- group_name: Matched known type OR UPPERCASE version of group_label
- feature_name: Convert feature_label to UPPERCASE
