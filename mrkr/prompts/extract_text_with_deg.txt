# Extraction Guidelines

## What to Extract
For each cell type and marker gene pair you find:
- Infer the species/organism (use Latin names with underscores: homo_sapiens, mus_musculus, etc.)
- Extract the EXACT text as it appears for the cell type (group_label) — preserve original capitalization
- Extract the EXACT gene name/symbol as it appears (feature_label) — preserve original capitalization
- Copy one or more complete sentences from the manuscript that mention BOTH the cell type and gene (source_rationale)
- The source_rationale MUST include BOTH the cell type AND the gene name

## source_rationale Rules (CRITICAL)
- Copy the EXACT text from the manuscript. Do NOT paraphrase, summarize, or modify in any way.
- Copy COMPLETE sentences — never truncate with "..." or ellipsis.
- The text must be an exact, contiguous substring of the manuscript that can be found via string matching.
- If a sentence mentions both a cell type and a gene, copy the full sentence.
- If multiple sentences are needed to capture context, copy all of them contiguously.

## Cell Type Matching (CRITICAL)
- For group_name: Match group_label to the MOST SPECIFIC known cell type from the lists above.
- ALWAYS prefer the most specific subtype. For example:
  - If the manuscript says "adipocytes expressed UCP1" and the DEG lists include both "ADIPOCYTE" and "ADIPOCYTE 1" through "ADIPOCYTE 7", you MUST determine which specific subtype is being referenced. If the context does not specify a subtype, use the parent name "ADIPOCYTE".
  - If the manuscript discusses "spermatogonia cluster 1" and the DEG lists include "SPERMATOGONIA CELL 1", use "SPERMATOGONIA CELL 1" — not the generic "SPERMATOGONIA CELL".
- Use biological knowledge to match naming variants (e.g., "naive CD4+ T cells" matches "NAIVE CD4+ T CELL").
- Be flexible with formatting: "T cell" vs "T-cell", "CD4+" vs "CD4 positive", etc.
- If no good match exists in the known cell types, normalize the group_label to UPPERCASE.

## data_id Assignment
- For each extraction, set data_id to the data source (file#sheet) from the known cell types list above that contains the matched group_name.
- If the group_name appears in multiple sources, prefer the most specific source (e.g., a subtype-level sheet over an "all markers" sheet).
- If no match, leave data_id as null.

## Normalization Rules
- group_name: Matched known type OR UPPERCASE version of group_label
- feature_name: Convert feature_label to UPPERCASE

## Source Information
- source_type: Always "text" for manuscript text extractions
