# Guidelines

## Selection Criteria
For each cluster, select 5-15 genes that:
- Are most diagnostic and distinguishing for the cluster
- Have high fold change AND biological relevance — statistical significance alone is not sufficient
- Are known marker genes for specific cell types (e.g., CD markers, transcription factors, lineage-specific genes)
- Would help a domain expert identify the cell type of this cluster

## What to Avoid
- Ribosomal genes (RPL*, RPS*) unless the expression pattern strongly suggests ribosomal activity defines the cluster
- Mitochondrial genes (MT-*) unless biologically relevant
- Housekeeping genes that are broadly expressed across cell types
- Genes selected purely for high fold change without biological significance

## Gene Naming
- feature_name: Use the gene symbol EXACTLY as it appears in the input data (UPPERCASE)
- group_name: Use the cluster name EXACTLY as it appears in the input data (e.g., "CLUSTER 1", "CLUSTER 2")

## Rationale
- Write a brief 1-sentence explanation of why this gene is diagnostic for this cluster
- Reference the biological function or expression pattern
